SETUP · ONCE

התקנה, פעם אחת

  1. מורידים את הקובץ social-agent.zip מהכפתור למעלה. לא פותחים אותו.
  2. נכנסים ל-Claude במחשב, ופותחים Settings › Capabilities. מוודאים שהאפשרות Code execution פועלת.
  3. פותחים Customize › Skills, לוחצים על +, ואז Create skill › Upload a skill.
  4. בוחרים את קובץ ה-ZIP שהורדתם. הסקיל social-agent מופיע ברשימה, ומוודאים שהוא מופעל.
  5. פותחים שיחה חדשה ומדביקים את ההודעה הראשונה מלמטה.

לפי מרכז העזרה של Claude, סקילים זמינים בכל התוכניות, כולל החינמית. שמות התפריטים משתנים לפעמים. אם משהו נראה אחרת, מחפשים "Skills" בהגדרות.
