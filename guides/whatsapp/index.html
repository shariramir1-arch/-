PART 1 · SETUP · ~10 MIN

חלק 1: מחברים מספר

שלב 1 מתוך 4

1פותחים חשבון

נכנסים ל-kapso.ai ← Start free. נרשמים ומקבלים פרויקט ראשון.

2מתקינים את הכלי ומתחברים

פותחים טרמינל ומדביקים, אחת אחרי השנייה:

npm install -g @kapso/cli@latest
kapso login

✓ נפתח דפדפן, מאשרים, והטרמינל כותב שאתם מחוברים.

3מחברים מספר וואטסאפ

kapso setup

נפתח מסך של Meta. נכנסים עם פייסבוק ובוחרים את המספר שנבחר למעלה. אחר כך בודקים שהוא מחובר:

kapso whatsapp numbers list

✓ המספר מופיע ברשימה.

4מחברים את Claude ל-Kapso

יוצרים תיקייה לפרויקט, נכנסים אליה בטרמינל, ומריצים את שתי הפקודות. הראשונה מלמדת את Claude לעבוד עם Kapso, והשנייה נותנת לו גישה לחשבון:

npx skills add gokapso/agent-skills
claude mcp add --transport http kapso https://api.kapso.ai/mcp

פותחים את Claude Code (claude), כותבים /mcp, ומתחברים ל-Kapso בדפדפן.

חשוב: ברירת המחדל במסך ההרשאות היא Read only, כלומר רק קריאה. כדי ש-Claude יוכל לשלוח הודעות, בוחרים Custom ומסמנים גם את שליחת ההודעות (messages:send).

FAQ

שאלות

אפשר עם המספר הרגיל של העסק?

כן, דרך האפשרות "וואטסאפ ביזנס הקיים". ממשיכים לעבוד באפליקציה, וההודעות מסתנכרנות. להתחלה עדיף מספר נפרד, כדי לבדוק בלי לחץ.

Meta לא מציעה מספר מוכן ומבקשת SMS

זה קורה כשאין מספר פנוי במאגר. אפשר לנסות שוב מאוחר יותר, או לחבר סים משלכם. ב-Kapso יש עמוד עזרה ייעודי ל-Instant setup.

משהו לא עובד

מעתיקים ל-Claude את הודעת השגיאה כמו שהיא, וכותבים "תתקן". ברוב המקרים הוא מסתדר לבד.
